# Security policy

Rumk is prerelease software. Security fixes are applied to the latest development version and may
not be backported to older prereleases.

Report suspected vulnerabilities through GitHub's private vulnerability reporting feature in the
repository's **Security** tab. Please do not disclose an unresolved vulnerability in a public issue.

Include the affected Rumk version, a minimal Makefile or configuration reproducer, the observed
impact, and whether the issue can cause command execution, file modification, or unsafe fixes.
