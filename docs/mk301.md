# MK301 - POSIX Make Portability

Select a source-syntax profile in your configuration:

```toml
[global]
dialect = "posix2024"
```

`gnu` remains the default. `posix2017` and its `posix` alias select POSIX.1-2017;
`posix2024` selects POSIX.1-2024. Both enable MK301 by default. Explicit rule
selection and inline suppression still apply. Unknown dialects, including `bsd`,
are rejected instead of silently using GNU behavior.

Both profiles report GNU conditionals, functions, multiline definitions,
assignment modifiers, target-specific variables, pattern and grouped rules,
order-only prerequisites, double-colon rules, and reserved GNU special targets.
The entry Makefile must start with `.POSIX:` before other statements. Included
files are checked at their own source locations without requiring another marker.

The editions differ deliberately. POSIX.1-2024 standardizes `::=`, `:::=`, `+=`,
`?=`, `!=`, optional includes, multiple include paths, `.PHONY`, `.WAIT`,
`.NOTPARALLEL`, pattern macro substitution, and `$^`/`$+`. POSIX.1-2017 reports
these constructs. GNU `:=` remains nonportable to both editions. The 2024 special
assignment operators require a preceding blank; `.WAIT` and `.NOTPARALLEL` must
not have prerequisites or commands. Plain `include` is supported by both editions.

The 2017 profile disables MK201's `.PHONY` advice by default because that edition
does not specify `.PHONY`. Explicitly enabling MK201 overrides this choice.

This is a portability check over Rumk's GNU source parser, not a separate POSIX
interpreter or certification of a complete build. It does not execute Make,
validate shell command portability, resolve arbitrary generated syntax, or model
every implementation's built-in rules. Diagnostics have no automatic fix:
rewriting an assignment operator or dependency can change build behavior.

The edition boundaries follow the Open Group specifications for
[POSIX.1-2017 make](https://pubs.opengroup.org/onlinepubs/9699919799/utilities/make.html)
and [POSIX.1-2024 make](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/make.html).
