# MK106 - Space Static Rule Headers

An opt-in layout rule with safe fixes in `check` and `fmt`:

```make
# Before
all  :  first   second | setup ; @echo done
# After
all: first second | setup ; @echo done
```

Enable with `[MK106] enabled = true` in TOML, or
`rumk fmt --extend-enable MK106`. Target and prerequisite order, order-only
separators, comments, inline shell commands, and line endings are preserved.

Only ordinary static names in single-line, single-colon headers are formatted.
Dynamic names, escapes, patterns, archives, grouped or double-colon rules,
target-specific assignments, and continuations are left alone. The rule does
not reflow long lists or align adjacent rules. Tests compare GNU Make's command
output and prerequisite order before and after the edit, and verify idempotence.
