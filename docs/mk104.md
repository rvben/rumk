# MK104 - Keep Recipes Short

Reports recipes exceeding `max-lines` logical command lines. This is an **opt-in
style convention**, not a measure of correctness or shell complexity. The default
limit is 10. Continuations count once, inline recipes count, and empty commands
and full-line shell comments do not count. Each multi-target declaration reports
once. `.ONESHELL` still counts logical lines, because the policy concerns recipe
size rather than how many shells Make launches.

```toml
[MK104]
enabled = true
max-lines = 10
```

Literal inactive branches are excluded. Conditions requiring evaluation can
contribute commands from multiple possible branches; this is a source-size check.
The rule provides no automatic fix: extracting a script requires choosing its
arguments, environment, and failure behavior.

A positive integer is required. Configuration inheritance, severity overrides,
per-file ignores, and inline suppression work as for other rules. This rule runs
in `check`, never in `fmt`.

Inspired by checkmake's configurable
[maxbodylength](https://github.com/checkmake/checkmake/tree/main/rules/maxbodylength)
policy. Rumk counts logical commands rather than physical continuation lines.
