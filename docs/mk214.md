# MK214 - Avoid Global Error Suppression

Reports an active `.IGNORE:` declaration with no prerequisites. Enabled by
**default**, with warning severity. Runs in `check`, never in `fmt`.

```make
# Suppresses recipe failures throughout the build:
.IGNORE:

# Scope an intentional exception instead:
.IGNORE: cleanup
```

The project evaluator resolves literal and statically expanded declarations
across includes. Findings use the declaring file's real location. Inactive
branches, unknown conditions, unknown prerequisite expressions, define bodies,
and recipe text are not interpreted as active global declarations. Repeated
inclusion of the same declaration reports its source location once.

No automatic fix is offered. Removing error suppression changes build behavior;
the maintainer must decide which failures are expected.

```toml
[MK214]
severity = "error"
```

Use a scoped suppression comment or `enabled = false` when global suppression is
intentional. This rule checks declarations, not command-line `make -i` or shell
error handling such as `|| true`.

Basis: GNU Make's [.IGNORE special target](https://www.gnu.org/software/make/manual/html_node/Special-Targets.html).
Inspired by unmake's GLOBAL_IGNORE warning.
