# MK004 - Do Not Mix Rule Separators

## What this rule does

Reports a concrete target declared with both ordinary `:` rules and
double-colon `::` rules in the same evaluated project.

## Why this matters

Ordinary rules merge prerequisites and select one recipe. Double-colon rules
are independent. GNU Make requires every declaration for one target to use the
same rule type.

## Examples

### Correct

```makefile
report:: data.json
	generate-summary

report:: charts.svg
	generate-charts
```

### Incorrect

```makefile
report: data.json
	generate-summary

report:: charts.svg
	generate-charts
```

## Configuration

MK004 is enabled by default and has no rule-specific options.

## Automatic fixes

MK004 does not offer fixes because choosing `:` or `::` changes recipe and
prerequisite semantics.

## Special cases

- Rumk checks definitely active declarations across included Makefiles.
- Dynamic and pattern target names are excluded from this concrete-name check.
- Structural conditional errors suppress this diagnostic.

## Basis

This is a GNU Make rule-type constraint.

- [GNU Make manual: Double-Colon Rules][double-colon]

[double-colon]: https://www.gnu.org/software/make/manual/html_node/Double_002dColon.html
