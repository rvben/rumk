# MK105 - Space Assignment Operators

An **opt-in layout rule** that uses one space around the operator in ordinary
single-line assignments. Runs in both `check` and `fmt`, with safe fixes.

```make
# Before
CC:=cc
VALUE=  text  # two spaces before this comment belong to the value

# After
CC := cc
VALUE = text  # two spaces before this comment still belong to the value
```

```toml
[MK105]
enabled = true
```

Or use `rumk fmt --enable MK001,MK101,MK105` for one run. The existing formatter
keeps its defaults; enabling this rule is a deliberate style choice.

Only the padding before the operator and the leading spaces/tabs Make discards
before the value are changed. The operator, value, trailing spaces, comments,
line endings, final newline, and indentation are preserved. Empty assignments
end at the operator. Unicode positions are reported as character columns.

Names must consist of ordinary letters, digits, underscores, dots, hyphens,
and spaces/tabs (including assignment modifiers). Dynamic or escaped names,
continuations, target-specific assignments, define bodies, and recipe shell
assignments are left alone. This initial rule does not align adjacent assignments,
reflow values, strip trailing whitespace, or change expansion timing.

All seven GNU assignment operators keep their spelling, including `?=`, `!=`,
and `:::=`. Fixes are idempotent and obey inline suppression and fix allowlists.
GNU Make probes compare expansion and recipe output before and after formatting.

Basis: GNU Make's rules for
[setting variables](https://www.gnu.org/software/make/manual/html_node/Setting.html).
