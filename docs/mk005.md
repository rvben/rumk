# MK005 - Keep Special Targets on Their Own Left-Hand Side

## What this rule does

Reports supported GNU Make special targets when they share the left-hand side
of a rule with another target.

## Why this matters

Special targets control Make itself. Combining one with an ordinary target can
change the declaration from a special directive into a different multi-target
rule.

## Examples

### Correct

```makefile
.PHONY: clean all
```

### Incorrect

```makefile
.PHONY all: clean
```

## Configuration

MK005 is enabled by default and has no rule-specific options.

## Automatic fixes

MK005 does not offer fixes because Rumk cannot safely decide which words were
intended as targets and which were intended as prerequisites.

## Special cases

- Multiple prerequisites after the colon are valid.
- The rule covers GNU Make targets such as `.PHONY`, `.ONESHELL`, `.POSIX`,
  `.PRECIOUS`, `.SILENT`, and `.SUFFIXES`.
- Ordinary multi-target rules are unaffected.

## Basis

The special-target meanings come from GNU Make; the diagnostic prevents an
ambiguous left-hand-side construction.

- [GNU Make manual: Special Built-in Target Names][special-targets]

[special-targets]: https://www.gnu.org/software/make/manual/html_node/Special-Targets.html
